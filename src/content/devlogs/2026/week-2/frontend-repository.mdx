## Getting started

This week the `frontend` repository went up with a Next.js, React, and TypeScript project. That closed the first two website issues: setting up the repository and the frontend project.

## A first look at the product

The second commit was a big one: a software quality workspace with sidebar navigation, a code analysis view, a bug review view, a report view, metric and service cards, and a preview dialog. All of it runs on static preview data. Nothing talks to a backend yet.

It was useful mostly as a way to see the product shape on screen. Some of it was too much for an under-development page, and we expect to cut it back.
